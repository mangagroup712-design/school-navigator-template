# School Navigator Template

汎用的な校内ナビゲーションのテンプレートです。実在の学校名、校舎画像、教室名、座標、イベント情報、人物画像は含めていません。  
Example: https://school-navigator-template.pages.dev/

## セットアップ

Node.js をインストールしたあと、依存関係をインストールします。

```sh
npm install
```

## 環境データの設定

実際に利用するデータは `env/` に配置します。

- `env/manifest.js`: PWAの表示名 (任意)
- `env/mapinfo.js`: 階層、部屋名、検索語、座標  ※部屋の前に始点・終点を表す座標も登録します。
- `env/map/*.svg`: 各階の地図画像

`npm run dev` または `npm run build` の実行時に、`env/` の内容が生成先の `public/env/` へコピーされます。`public/env/` は生成物なのでGitへ登録しません。

```sh
npm run dev
npm run build
```

`env/` に個人情報、学校固有の機密情報、許諾のない画像やイベント情報を追加しないでください。公開する場合は、画像の著作権・肖像権・施設情報の公開許可を確認してください。

## 地図エディタ
`npm run dev` 実行中に http://localhost:5173/editor.html を開くと、`env/mapinfo.js` と階層の地図をGUIで編集できます（開発サーバー専用で、ビルドには含まれません）。

- **画像・PDFから取り込む**：間取り図の画像（PNG/JPG）や PDF から、歩行エリアと部屋を自動検出して取り込みます
  - PDF は各ページを1つの階として扱います。「全ページを取り込む」で、1ページ目を今の階、以降のページを次の階へまとめて取り込めます（全ページ同じ範囲で切り抜くので、階どうしの位置がそろい、階段も自動でリンクされます）
  - 通路の色（既定は自動推定。プレビューをクリックして指定も可）の部分を歩行エリアに、線で囲まれたそれ以外の色の領域を部屋にします
  - 部屋は「部屋1」「部屋2」…の仮名で取り込まれ、通路に接する辺に lineDot が自動配置されます。取り込み後に名前を付けてください
  - 画像は下絵として重ねて表示されるので、ずれた箇所はそのまま手直しできます
  - 検出した通路は1つの多角形に結合され、細かな段差もならされます
  - 部屋・通路は壁の線の中心まで広げ、近い辺どうしをそろえるので、隙間や重なりが出にくくなっています
  - 領域の中に浮いた線（階段の記号）がある場所は「階段」として取り込み、上下の階の近い位置にある階段と自動でリンク（同じ StairID）します
- **フロア形状**：SVGを用意しなくても、エディタで地図を作れます
  - **四角形** (`S`) / **多角形** (`P`)：歩行エリア（廊下など）・障害物（柱・吹き抜け）・装飾（校庭など）を描画。多角形は `Shift` で水平・垂直にそろい、始点クリック・ダブルクリック・`Enter` で確定
  - 選択した形状はドラッグで移動、頂点ハンドルで変形（右クリックで削除）、辺の中点ハンドルで頂点を追加
  - 重なった歩行エリアは1つの輪郭で表示されます。「歩行エリアを結合」で1つの多角形にまとめられます（囲まれた穴は障害物になります）
  - 保存時に `env/map/*.svg` を生成します。歩行エリアは経路探索にそのまま使われます
  - 建物の外形（フロアの輪郭）は歩行エリアと部屋から自動で作られ、SVG の一番下に描かれます。形を指定したい場合は種類「外形」で描いてください
  - 既存のSVGから切り替えると、元のSVGは下絵として表示されます。写真や画像も「下絵」として読み込んでなぞれます（下絵は保存されません）
- **部屋** (`R`)：地図上をドラッグして部屋を追加
- **選択** (`V`)：部屋のドラッグで移動、角のハンドルでリサイズ、右パネルで名前・検索語・StairID などを編集
- **lineDot** (`D`)：クリックで選択中の部屋の経路の出入口を設定
- **階段**：階段の部屋にはリンク先の階が表示されます（未リンクは赤）。「階段を自動リンク」または部屋パネルの「近くの階段とリンク」で、上下の階の近い位置にある階段とつなげられます
- 階層の追加・並べ替え、既存SVGのアップロード（`env/map/` に保存）
- 「チェック」欄に名前の重複、lineDot 未設定・歩行エリア外、分断された歩行エリア、対応する階がない StairID などを表示
- `Ctrl+S` で保存。`Ctrl+Z` / `Ctrl+Y` で元に戻す／やり直し

## デバッグツール
`src/debug.ts`の変数`debug`が`true`の際、デバッグモードとして以下の変更が行われます。
- マップ上で、`env/mapinfo.js`に用いる部屋情報を取得する機能
  - マップの右下をShift左クリック、次に左上をShift左クリックすると位置情報を含んだ`RoomInfo`オブジェクトがクリップボードにコピーされます。
  - `Alt`左クリックすると、その位置を`lineDot`としてクリップボードにコピーできます。
    `lineDot`が設定された部屋は、経路の点線がその座標から始まります。
